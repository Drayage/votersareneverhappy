# 00. 게임 개요

## 1. 비전 한 문장

> **"덱이 아니라 도시를 키운다. 그리고 도시를 키우는 진짜 레버는 시장(市場)이다."**

도미니언의 손맛(카드 구매 → 덱 순환 → 엔진 빌딩)을 유지하되, 플레이어의 의사결정 무게중심을
"내 덱에 무엇을 넣을까"에서 **"무엇을 살 수 있게 만들까(시장 구성)"** 로 옮긴 게임이다.
전투가 없으므로 모든 긴장은 **숫자 성장 곡선 vs 평가 목표** 사이에서 발생한다.

## 2. 코어 루프

```
[평가 주기 1] 8턴 플레이 ─▶ 평가(목표 70)   ─▶ 점수→자금 변환 ─▶ 상점
[평가 주기 2] 8턴 플레이 ─▶ 평가(목표 180)  ─▶ 점수→자금 변환 ─▶ 상점
[평가 주기 3] 8턴 플레이 ─▶ 평가(목표 420)  ─▶ 점수→자금 변환 ─▶ 상점
[평가 주기 4] 8턴 플레이 ─▶ 평가(목표 900)  ─▶ 점수→자금 변환 ─▶ 상점
[평가 주기 5] 8턴 플레이 ─▶ 평가(목표 1800) ─▶ 게임 클리어
```

### 한 턴의 흐름

```
턴 시작
  ↓ 5장 드로우
  ↓ 액션 사용 (기본 1회, 액션 카드로 추가 액션 획득)
  ↓ 재물 사용 → 예산 획득
  ↓ 카드 구매 (예산으로 시장에서 구매, 기본 1회)
  ↓ 사용/구매한 카드 정산 (점수 카드의 즉발/지속 점수 적립)
턴 종료
  ↓ 손패·플레이 영역 → 버린 더미
  ↓ 시장 카드 강제 추가 (후보 3장 중 1장 선택, 10종이면 1종 교체)
다음 턴
```

8턴이 끝나면 **그 주기 동안 누적한 도시 발전 점수**로 평가를 받는다.

## 3. 승패 규칙

- 각 평가에서 **목표 점수 이상**이면 통과 → 다음 주기로.
- 목표 미달이면 **게임 오버**(로그라이크: 런 종료, 다음 런은 새 시작 덱·새 시장).
- 5회 모두 통과하면 **클리어**. (확장: 5차 이후 무한 모드 점수 경쟁 가능)

## 4. 왜 재미있는가 — 3중 압박

1. **자원 분리 압박**: 예산(구매력)·점수(승리)·자금(상점)이 분리돼 있어, 한 가지만 키우면 무너진다.
2. **시장 진화 압박**: 매 턴 시장에 카드가 강제로 들어오고, 10종이 차면 아끼던 카드도 밀려난다.
   "지금 이 카드를 시장에 남길 것인가"가 매 턴의 핵심 결정.
3. **평가 곡선 압박**: 목표가 2.5~3배씩 뛰므로 단순 누적으로는 못 따라간다. **배수·정산 엔진**이 필요.

## 5. 용어집

| 용어 | 정의 |
|------|------|
| **예산 (Budget)** | 턴 중 카드 구매에만 쓰는 자원. 재물 카드로 획득. 턴마다 리셋. |
| **도시 발전 점수 (Score)** | 승리 조건이 되는 핵심 점수. 점수 카드·정산으로 획득. 주기 동안 누적. |
| **자금 (Fund)** | 평가 종료 시 점수 1:1 변환되는 메타 재화. 상점에서만 사용. |
| **시장 (Supply)** | 구매 가능한 카드 공급처. 최대 10종. 매 턴 강제 진화. |
| **평가 (Evaluation)** | 8턴마다 도래하는 점수 검사. 목표 미달 시 게임 오버. |
| **태그 (Tag)** | 카드가 가진 1~3개의 분류표. 시너지의 핵심. 총 15종. |
| **즉발 점수** | 사용 즉시 1회 발생하는 점수. |
| **지속 점수** | 특정 트리거(예: 관광 카드 사용)마다 반복 발생하는 점수. |
| **정산 점수** | 평가 시점에 보유 카드/조건을 보고 일괄 계산되는 점수. |
| **정산 카운트 기준** | 정산은 **내 덱 전체 보유 카드**를 기준으로 센다(시장이 아님). |
| **유물 (Relic)** | 상점에서 사는 영구 효과 아이템. 카드보다 강력. 총 60종 목표. |
| **아키타입 (Archetype)** | 특정 태그군에 집중한 도시 빌드 정체성(관광/산업/과학/문화/복지 등). |
| **런 (Run)** | 게임 1회차. 시작 덱과 시장 후보가 매번 달라진다. |

## 6. 설계 목표 우선순위

1. **태그 중심 빌드 다양성** — 매 런 다른 도시를 만든다. (최우선)
2. **시장 진화의 의미성** — 시장 결정이 항상 트레이드오프이게 한다.
3. **3종 자원의 동시 저글링** — 한 축만 키우면 못 이기게 한다.
4. **읽기 쉬운 카드** — 초보도 즉발/단순 정산 카드로 클리어 가능.
5. **무한 콤보 차단** — 깨지는 루프를 구조적으로 막는다.
