# 01. 핵심 시스템

## 1. 3종 자원 모델 (재확인)

| 자원 | 생성원 | 용도 | 수명 | 비고 |
|------|--------|------|------|------|
| **예산(Budget)** | 재물 카드 | 시장 카드 **구매 전용** | 매 턴 리셋 | 도미니언 동전. 점수 구매 불가 |
| **도시 발전 점수(Score)** | 점수 카드/정산 | **승리 조건** | 주기(8턴) 누적 | 카드 구매 불가 |
| **자금(Fund)** | 평가 후 점수 1:1 변환 | **상점 전용** | 메타 보존 | 플레이 중 사용 불가 |

세 자원은 서로 변환 경로가 **단방향·제한적**이다:
- 점수 → 자금 (평가 시 자동, 1:1)
- 예산 ↔ 점수 (불가)
- 자금 → (상점에서 카드/유물/강화/정책)

이 비대칭이 "예산을 더 벌까, 점수를 더 낼까"라는 매 턴의 핵심 딜레마를 만든다.

## 2. 턴 구조 상세

### 2.1 기본 수치

| 항목 | 기본값 | 비고 |
|------|--------|------|
| 손패 드로우 | 5장 | 도미니언과 동일 |
| 기본 액션 | 1 | 액션 카드 사용에 소비. 추가 액션은 액션 카드로 |
| 기본 구매 | 2 | 카드 2장 구매. 추가 구매는 카드/유물로 |
| 시작 예산 | 0 | 재물 카드를 "사용"해야 예산 발생 |

### 2.1.1 플레이 코스트 (도미니언과 다른 점)
도미니언은 "액션 카드만 액션을 소비하고 재물·점수는 공짜"지만, 본작은 **모든 카드에 플레이 코스트**를 둔다.
- **타입별 기본값**: 재물 **0** / 액션 **1** / 점수 **0** (액션 풀에서 차감).
- **효과에 따라 조절**: 강력한 즉발 점수 폭탄(산업단지·세계박람회·매표·대규모공약 등)은 `playCost: 1`을 매겨,
  드로우만으로 한 턴에 몰아치지 못하게 한다 → **액션 엔진(주민센터·지하철 등)을 키워야** 폭탄을 여러 장 던질 수 있다.
- 데이터에서 카드별 `playCost`로 자유 지정(미지정 시 위 기본값).

### 2.2 페이즈

1. **드로우 페이즈**: 덱에서 5장. 덱이 부족하면 버린 더미를 섞어 보충.
2. **플레이 페이즈**: 손의 카드를 사용. 각 카드의 **플레이 코스트만큼 액션을 소비**(재물·대부분 점수=0, 액션=1, 폭탄=1).
3. **재물 페이즈**: 손의 재물 카드를 사용 → 예산 적립(플레이 코스트 0).
4. **구매 페이즈**: 예산으로 시장 카드 구매. 구매한 카드는 버린 더미로(도미니언 규칙).
5. **점수 적립**: 이번 턴 사용/발동된 즉발·지속 점수를 주기 누적 점수에 더한다.
6. **클린업**: 손패·플레이 영역 → 버린 더미.
7. **시장 진화**: 후보 5장 중 1장을 시장에 추가(아래 3.3).

> **점수 카드의 처리**: 점수 카드는 "사용"하여 즉발 점수를 내거나, 덱에 보유한 채 평가 시 정산된다.
> 도미니언의 영지(Estate)처럼 **손에 들면 드로우를 막는 약점**이 있어, 점수 카드 과다 적재는 패널티가 된다.

## 3. 시장(Supply) 시스템 — 핵심

### 3.1 규칙

- 시장에는 **최대 10종류**의 카드만 존재한다. (각 종류는 충분한 재고를 가진 더미)
- 매 턴 종료 시 **카드 후보 5장**이 제시된다(v0.11.2: 3→5 — 카드 풀이 138장까지 늘어나며
  좁은 후보 폭에서는 특정 태그·신규 카드가 좀처럼 안 걸리는 문제를 완화).
- 플레이어는 반드시 **1장을 선택해 시장에 추가**한다. (거부 불가)
  - 시장이 10종 **미만**이면: 그냥 추가.
  - 시장이 **이미 10종**이면: **기존 1종을 제거**하고 새 카드를 추가. (제거 대상은 플레이어가 선택)
  - **교체 쿨다운**(v0.12.5): 방금 내보낸 카드는 이후 **2번의 후보 세트 동안 다시 뜨지 않는다**
    (`marketCooldown`, `MARKET_REMOVE_COOLDOWN=2`). 애써 뺀 카드가 곧바로 후보로 되돌아오는 헛수고 방지.
- 즉 9턴이 지나면 시장은 항상 포화 상태이고, 이후 매 턴은 **교체(swap) 결정**이 된다.

### 3.2 시작 시장

런 시작 시 시장에는 **기본 카드 4종**이 미리 깔려 있다 (예산/점수 양쪽의 저티어 카드).
예: `세금 징수(재물)`, `소규모 공원(점수)`, `민원 처리(액션·드로우)`, `현수막(홍보 즉발)`.
나머지 6칸은 플레이로 채워진다.

### 3.3 후보 5장 생성 규칙 (빌드 유도의 핵심)

후보는 완전 무작위가 아니라 **가중 추첨**한다.

- 플레이어 덱 + 현재 시장에 많은 태그일수록 그 태그 카드가 후보에 **잘 등장**(가중치 ↑).
- 단, 항상 **최소 1장은 "오프-컬러"(현재 빌드와 다른 태그)** 를 끼워 넣는다.
  → 한 우물만 파게 두지 않고, 매 턴 "정체성을 고수할까, 곁가지를 칠까" 결정을 만든다.
- 평가 후반일수록 고티어(비싼) 카드 등장 확률 ↑.
- 슬롯 5장 중 1장은 태그 가중 없는 완전 무작위 — 카드 풀이 커질수록 잘 안 걸리던 카드도
  볼 기회를 준다.

실제 가중치(`market.ts` `generateCandidates`):
```
후보 슬롯 1: 빌드 메인 태그 가중 75% / 무작위 25%
후보 슬롯 2: 빌드 서브 태그 가중 67% / 무작위 33%
후보 슬롯 3: 빌드 메인 태그 가중 재적용(75%/25%) — 빌드 방향을 한 번 더 밀어줌
후보 슬롯 4: 항상 오프-컬러(메인/서브 외 태그) 우대에서 추첨
후보 슬롯 5: 완전 무작위(태그 가중 없음)
```

### 3.4 왜 "시장을 키운다"인가

- 정산 점수는 **내 덱**을 보지만, 내 덱을 채우려면 **시장에 그 카드가 있어야** 산다.
- 시장 10칸은 곧 **이번 런의 가능성 한계**. 칸을 무엇으로 채우느냐가 빌드 그 자체.
- 강제 교체 때문에, 핵심 카드를 충분히 산 뒤에는 과감히 빼고 다음 엔진 부품을 들여야 한다.
- 결과적으로 플레이어는 "내 덱 최적화"보다 **"시장 포트폴리오 관리"** 에 더 많은 뇌를 쓴다.

## 4. 평가(Evaluation)

| 차수 | 목표 점수 | 누적이 아니라 **그 주기(8턴) 동안 획득한 점수** |
|------|-----------|----------------------------------------------|
| 1차 | 70 | |
| 2차 | 180 | |
| 3차 | 420 | |
| 4차 | 900 | |
| 5차 | 1800 | |

> **중요 설계 결정**: 평가 점수는 **주기별로 리셋**한다(누적 아님). 각 주기는 자기 안에서
> 엔진을 가동해 목표를 넘겨야 한다. 정산 점수는 "그 주기 마지막 턴(8턴째) 종료 시" 1회 계산된다.

평가 처리:
1. 8턴째 점수 적립까지 끝낸 뒤, **정산 점수**를 계산해 더한다.
2. 합계 ≥ 목표 → 통과. 미달 → 게임 오버.
3. 통과 시 합계 점수만큼 **자금**을 획득.

## 5. 자금 & 상점

### 5.1 변환

- 평가 통과 시: `획득 자금 = 그 주기 도시 발전 점수 합계` (1:1).
- 예: 8턴 합계 327점 → 327 자금. (목표를 초과 달성할수록 상점이 풍족 → "오버킬 보상")

### 5.2 상점 메뉴

평가 사이에 상점이 열린다. 자금으로 아래를 구매:

| 항목 | 효과 | 가격대(자금) | 비고 |
|------|------|-------------|------|
| **유물 구매** | 영구 효과 1개 | 보통 80 / 희귀 180 / 전설 350 | 슬롯 제한(아래) |
| **시장 카드 추가** | 원하는 카드를 시장에 1종 직접 투입 | 60~150 | 후보 추첨을 건너뛰고 핵심 부품 확보 |
| **카드 강화** | 내 덱의 카드 1장을 강화판으로 교체 | 50~120 | 도미니언 "개조" 느낌. 예산↑/점수↑/태그추가 |
| **특수 정책** | 이번 주기 한정 강화(기본 4종 + 태그형 5종) | 100~150 | 예: "매 턴 구매 +1", "지정 태그 정산 점수 ×1.5" (§05 정책 9종) |
| **카드 제거** | 시작 덱 약카드(낡은 공약 등) 영구 폐기 | 30 | 덱 압축 |

### 5.3 유물 슬롯

- 유물은 무제한이 아니라 **슬롯 제한**(권장 시작 3칸, 상점/정책으로 최대 6칸까지 확장).
- 슬롯이 차면 교체. → 유물도 "포트폴리오"가 되어 후반 빌드 변환을 강제.

### 5.4 상점 갱신

- 상점에 노출되는 유물/정책 목록은 **무작위 N개**(권장 유물 3 + 정책 2 + 강화 후보 2).
- 자금으로 **새로고침(reroll)** 가능(권장 20 자금, 누를수록 +10 증가).

## 6. 시스템 간 인과 요약 (한 장 그림)

```
재물 카드 ──> 예산 ──> 시장에서 카드 구매 ──> 덱 성장
                                   │
점수 카드 ──> 도시 발전 점수 <──────┘ (좋은 점수/엔진 카드를 사야 점수가 큰다)
   │
   └─(평가)─> 자금 ──> 상점(유물/강화/시장/정책) ──> 다음 주기 더 강한 엔진

시장(10칸) = 살 수 있는 것의 한계 = 이번 런 빌드의 그릇
태그 = 위 모든 카드/유물을 묶어 폭발시키는 시너지 축
```
