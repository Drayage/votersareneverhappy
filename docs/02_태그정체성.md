# 02. 태그 정체성 & 도시 아키타입

> 이 게임의 **최우선 설계 목표는 태그 중심 빌드 다양성**이다. 카드 타입(재물/액션/점수)은 "무엇을 하는가"이고,
> 태그는 "어떤 도시를 만드는가"이다. 각 태그는 고유한 **역할·강점·약점·시너지 파트너**를 가진다.

## 0. 15개 태그 한눈에

| 태그 | 분류 | 한 줄 정체성 (고유 동사) | 주 파트너 | 견제/약점 |
|------|------|--------------|-----------|-----------|
| 상업 | 생산 | **산다** — 예산·추가 구매·구매 트리거 | 관광, 산업 | 점수 자체 산출은 약함 |
| 산업 | 생산 | **꽂는다** — 카드당 최대 즉발 점수 + 환경 벌점 | 상업, 교통 | 환경 카드와 상극 |
| 과학 | 생산 | **연구한다** — 연구지수(🔬)를 모아 잠긴 카드 해금 + 정산 곱셈(×) | 문화·교육, 행정 | 램프 느림, 곱할 기반 필요 |
| 주거 | 기반 | **넓힌다** — 인구=정산 베이스, 카드 수 보너스 | 복지, 교통 | 단독으론 밋밋 |
| 교통 | 기반 | **돌린다** — 드로우·체이닝 + **순환(리사이클)의 본가** | 관광, 행정 | 점수 직접 산출 적음 |
| 행정 | 기반 | **공급한다** — 액션·구매 인프라 + 재처리·회전 정산 | 과학, 모든 엔진 | 점수 직접 산출 없음 |
| 문화 | 가치 | **쌓는다** — 평면 가산(+) 정산 기둥 + 공연(지속·앙코르) | 과학, 관광 | 곱셈 없어 단독 상한 낮음 |
| 관광 | 가치 | **울린다** — 지속 점수 트리거의 천국 (+ 지속 건물) | 문화, 교통 | 재정 플레이는 트리거 미발동, 엔진 의존 |
| 교육 | 가치 | **적립한다** — 학습 레벨 누적 복리 | 과학, 행정 | 즉효성 0(장기전) |
| 복지 | 가치 | **보장한다** — 벌점→점수 전환 + 목표비례 안정 세입 | 산업, 부패/포퓰 | 스케일링 없음 |
| 환경 | 가치 | **씻는다** — 게이지 정화 + 환경 카운트 정산 | 과학, 복지 | 산업과 동시 채용 어려움 |
| 홍보 | 정치 | **동원한다** — 즉발 버스트 + 군중 연계(먼저 낸 수 비례) | 포퓰리즘, 문화 | 일회성, 엔진 아님 |
| 정치 | 정치 | **약속한다** — 정산 고정 공약 + 합의(연계) | 복지, 포퓰리즘 | 즉발 0, 주기 단위 회수 |
| 부패 | 정치(하이리스크) | **당겨쓴다** — 즉시 강력 + 부패 게이지 누적 | 상업, 포퓰리즘 | 벌점 관리 실패 시 붕괴 |
| 포퓰리즘 | 정치(하이리스크) | **터뜨린다** — 즉발 폭발 + 다음 목표 상향, 유세(회전 정산) | 홍보, 부패 | 후반 목표 감당 리스크 |

## 0.5 공통 문법 (메커니즘 사전) — 구현 기준

여러 태그가 공유하는 문법. **같은 문법을 쓰더라도 태그별 "창구"가 달라야 한다**(아래 소유권 참조).
단순 태그 스왑 복제는 금지 — 능력이 다르거나, 같은 축이라면 가격·규모 사다리가 명확해야 한다.

| 문법 | 엔진 키 | 내용 | 소유권(본가 → 변주) |
|------|---------|------|------|
| 연구지수 🔬 | `gainResearch` / `costResearch` | 과학 카드가 생산하는 **누적 재화**(턴/주기 유지). 시장의 연구 비용 카드를 해금 구매 | **과학 전용** |
| 리사이클 | `recycleInPlay` | 이번 턴 낸 카드를 덱 위로 되돌려 같은 턴 재사용. 액션 소모형만(무한 방지) | **교통**(순환선·셔틀) → 행정(재처리), 문화(앙코르) |
| (지속 N턴) | `persistTurns` | 낸 카드가 N턴 플레이 영역에 남아 트리거 유지 — "건물" 문법 | **관광/문화**(명소·공연장) → 교통/행정(관제) |
| 회전 정산 | `settlementPerPlays` | 이번 주기 **낸 카드 수** 기반 정산 (보유 아님) | 행정(전체·소형) / 문화·관광(자기 태그) / 포퓰리즘(전체·대형) |
| 지속 트리거 | `onPlayTag` | "재정 외 X 카드를 낼 때마다 +N". **소스당 턴 6회** 상한, 재정 플레이는 미발동 | **관광** → 문화, 산업, 주거 |
| 연계 | `comboScore` | 먼저 낸 같은 태그 수 비례 즉발 (상한) — 낸 **순서**를 판단하게 함 | 태그별 1장 내외 |
| 정산 카운터 | `settlementPerTag` | 보유 X 카드당 +N. **손패 사용 불가**(deadInHand)와 세트 | **문화/주거/상업** (불리기 축) |
| 주기 점수 배수 | `cycleScoreMult` | 플레이로 쌓은 점수에만 ×. 정산 배수(과학)와 대칭 | 유물 전용 (플레이형 덱 지원) |
| 손패 사용 불가 | `deadInHand` | 정산 전용 카드는 손패를 썩힌다 — 불리기의 비용 | 순수 정산 카드 공통 |
| 지속 자원(Seaside) | `duration` | (지속) 카드가 남아 있는 동안 매 턴 시작 시 자원 재발동 | 교통/상업(부두·무역선) |
| 필터(선택) | `discardThenDraw` | 손패에서 원하는 만큼 버리고 그만큼 드로우 — 정크 세탁 | **행정**(문서고 정리) |
| 폐기(선택·압축) | `trashFromHand` | 손패 카드를 게임에서 영구 제거 — 덱 압축의 인게임 창구 | **행정**(행정 감사) |
| 두 번 사용(선택) | `playTwice` | 손패 1장을 액션 소모 없이 두 번 발동 (왕좌의 방) | **행정**(이중 결재) |
| 액션 환금 | `budgetPerAction` | 남은 액션 1개당 +N예산 — 비축 액션의 출구 | 행정/상업(잔업 수당) |

> **덱빌딩 공급 원칙**(도미니언 이식): 최대 단일 드로우 +4(공영방송), +3(간선급행버스). playCost 2~3 대형(메가
> 프로젝트/총동원령)으로 "액션 비축→대형 1발"의 의사결정 부여. 폐기/필터로 정산 뚱뚱덱이 오염되는 만큼 청소 수단도 공급.
>
> **미구현 로드맵**: 조건형 공약(정치 "X 달성 시 +N"), 복지 최소 점수 보장(settlementFloor).
> 구현 시 이 표로 승격한다. ※ 환경 임계 배수는 친환경 박람회(`settlementThresholdMult`)로 구현 완료.

## 1. 생산형 태그 (예산·고점수 엔진)

### 상업 (Commerce)
- **정체성**: 예산을 불리고 추가 구매를 제공하는 **경제 엔진**. 모든 빌드의 윤활유.
- **강점**: `+예산`, `+구매`, "구매 시 점수" 같은 효과. 상업이 두꺼우면 매 턴 2~3장씩 산다.
- **약점**: 상업만으로는 점수가 안 난다. 반드시 점수 산출 태그와 결합해야.
- **시그니처 효과**: "재물 카드 사용 시 +예산", "이번 턴 구매한 카드 1장당 +점수".
- **파트너**: 관광(구매가 점수로), 산업(비싼 점수 카드 구매력).

### 산업 (Industry)
- **정체성**: **한 방 고점수**. 큰 숫자를 즉발/정산로 꽂지만 **환경 벌점**을 동반.
- **강점**: 카드당 점수 수치가 가장 높음. "공장 가동: +12점" 류.
- **약점**: 산업 카드 보유 수에 비례해 **환경 벌점(정산 시 -점수)** 누적. 복지/환경으로 상쇄 필요.
- **시그니처 효과**: 고즉발 점수 + "정산 시 산업 카드당 -2점(환경오염)".
- **파트너**: 상업(구매력), 교통(가동 체이닝), 복지/환경(벌점 상쇄).

### 과학 (Science) — 고유 동사: **연구(축적·해금) + 곱셈(×)**
- **정체성**: **연구 엔진**. 과학 카드를 굴려 연구지수(🔬)를 모으고, 그걸로 시장의 **잠긴 고급 카드를 해금 구매**한다.
  정산 배수(×)는 여전히 과학의 것이지만, 이제 "사놓으면 곱해지는" 수동 효과가 아니라 연구로 사는 **도달 보상**이다.
- **핵심 메커니즘**:
  - `gainResearch` — 연구소(+2)·R&D 보조금(+3)·전자정부(+2) 등이 플레이 시 생산. 턴/주기가 지나도 유지.
  - `costResearch` — 스마트시티(🔬12)·국가연구망(🔬15)·핵융합 발전소(🔬10)·AI 행정망(🔬8)은 예산이 아니라 연구로만 구매.
  - `settlementGlobalMultPerTag` — 배수는 **이번 주기에 낸 과학 카드 수 × 소스 가산 합**. 사 모으기만 하는 스플래시는 ×1.
- **강점**: 전용 재화라 잡식 덱이 흉내낼 수 없음. 후반 배수+청정 산업(핵융합)으로 폭발.
- **약점**: 램프 계곡 — 연구에 투자하는 턴엔 점수가 안 나온다. 테크덱의 숙명.
- **차별점**: 문화(평면 가산)와 달리 과학은 **곱하거나 해금**한다. 절대 평면 점수를 쌓지 않는다.
- **파트너**: 교육(곱할 기반 = 학습 레벨 점수), 문화/주거(평면 기반), 행정(밀도↑).

## 2. 기반형 태그 (엔진 인프라)

### 주거 (Residential)
- **정체성**: **인구 = 정산 베이스**. 카드 장수/주거 수가 다른 점수의 곱셈 토대가 됨.
- **강점**: "주거 카드당 +점수", "덱의 카드 1장당 소량 점수". 넓고 얕게.
- **약점**: 단독으로는 폭발력 부족. 다른 태그의 배수를 받아야 빛남.
- **파트너**: 복지(인구 만족), 교통(통근), 과학(스마트 주거).

### 교통 (Transport)
- **정체성**: **드로우·체이닝 + 순환(리사이클)의 본가**. 손패를 돌리고, 낸 카드를 덱 위로 되돌려 같은 턴에 재사용한다.
- **강점**: `+드로우`, `+액션`, `recycleInPlay`. 회전덱의 심장.
- **약점**: 점수 직접 산출은 낮음. 무엇을 돌릴지(관광/산업/포퓰) 정해야 의미.
- **시그니처 효과**: 순환선(2장 되돌리고 +2드로우), 심야 셔틀(1장 되돌리고 +1드로우), 지하철망(+2드로우 +1액션), 환승 관제센터(지속 2턴 행정/교통 트리거).
- **경계**: 리사이클은 교통이 본가. 행정(야근=재처리)·문화(앙코르=점수 곁들임)는 변주 1장씩만.
- **파트너**: 관광(트리거 양산), 행정(액션 공급), 포퓰리즘(대형 즉발 재사용).

### 행정 (Administration)
- **정체성**: **액션·구매 공급 + 재처리 + 회전 정산**. 보이지 않지만 모든 엔진의 톱니.
- **강점**: `+액션`, `+구매`, 소량 리사이클(재처리), "이번 주기 낸 카드 수" 정산(시정 활동 보고서).
- **약점**: 점수 직접 산출 0에 가까움. 과투자하면 점수 부족.
- **시그니처 효과**: 주민센터(+2액션 +1드로우, 엔진 씨앗), 규제 완화(+2액션), 시청 효율화(+1액션 +1구매),
  야근 행정(재처리), 시정 활동 보고서(플레이 수 정산).
- **로드맵**: 인게임 카드 폐기(트래시)·드로우 필터링은 미구현 — 구현 시 행정의 압축 정체성이 완성된다.
- **파트너**: 과학(연구 밀도), 회전덱 전반.

## 3. 가치형 태그 (점수 콤보)

### 문화 (Culture) — 고유 동사: **평면 가산(+) + 즉발**
- **정체성**: **안정적인 점수 기둥**. 곱셈 없이 **꾸준한 평면 점수**(정산 장당 + 즉발 축제)를 낸다.
- **핵심 메커니즘**: `settlementPerTag culture`(문화 카드당 +N, 선형) + 즉발 점수(축제).
- **강점**: 변동 없이 두툼한 중간 점수. 과학의 **곱셈 대상이 되는 최고의 기반**.
- **약점**: 곱셈이 없어 단독 상한은 낮음. 예산 산출 없음(경제는 상업 의존).
- **시그니처**: 국립박물관(정산: 문화 카드당 +3), 도시 축제(사용:+5), 대극장(지속 2턴 공연), 앙코르 무대(리사이클 변주), 비엔날레(문화 정산 +50%).
- **차별점**: 과학(×)과 정반대 — 문화는 **절대 곱하지 않는다**(자기 태그 내 증폭 ×1.5는 예외). "안정 vs 폭발"의 안정 축.
  공연(지속)·앙코르(재사용)는 문화의 무대 테마 변주.
- **파트너**: 과학(문화 기반을 ×로 폭발), 관광(테마·트리거), 교육(학습 레벨 기반 보강).

### 관광 (Tourism)
- **정체성**: **지속 점수 트리거의 천국 + 지속 건물(명소)**. "재정 외 관광 카드를 낼 때마다 +N"이 본가.
- **트리거 계약**: 소스당 턴 6회 상한(다타수·저화력), 재정 플레이는 미발동 — 트리거 수입은 액션 경제에 묶인다.
- **강점**: 교통·문화와 결합 시 한 턴에 트리거가 폭주. (지속 N턴) 명소는 다음 턴에도 울린다.
- **약점**: 트리거(다른 카드 사용)가 없으면 빈손. 엔진 의존도 높음.
- **시그니처 효과**: 국제공항(+1드로우 + 관광 트리거 +2), 크루즈 터미널(관광/문화 +2), 먹자골목(지속 2턴), 순회 축제(관광 플레이 정산).
- **파트너**: 문화(테마 일치), 교통(트리거 양산).

### 교육 (Education) — 고유 동사: **누적 복리(시간 투자)**
- **정체성**: **장기 투자**. 점수를 "지금"이 아니라 **런 전체에 걸쳐 복리로** 쌓는다.
- **핵심 메커니즘**: **학습 레벨(eduLevel)** — 매 평가 주기 시작 시 *보유 교육 카드 수만큼* 누적 증가.
  교육 점수 카드는 정산에서 `학습 레벨 × N`을 낸다(`settlementEduLevel`).
- **강점**: 일찍 교육에 투자할수록 학습 레벨이 매 주기 쌓여 **후반에 거대한 평면 기반**이 됨 → 과학(×)과 환상의 조합.
- **약점**: **즉효성 0**. 1차엔 학습 레벨이 낮아 거의 점수가 안 됨. 인내가 필요한 빌드.
- **시그니처**: 도서관(학습 레벨 1당 +2), 교육청(+3/레벨), 종합대학(+5/레벨), 장학 재단(재물이면서 교육 복리에 기여), 병설 유치원(저가 교육 몸체).
- **차별점**: 과학은 "이번 평가 ×", 교육은 "성장률 자체를 영구히 적립" — 기생 보조가 아니라 **자기 승리 조건**을 가짐.
- **파트너**: 과학(학습 레벨 기반을 ×로 폭발), 행정(덱 압축으로 교육 밀도↑).

### 복지 (Welfare) — 고유 동사: **하방 보장 + 벌점→점수 전환**
- **정체성**: **리스크를 자산으로**. 환경/부패 벌점을 **오히려 점수로** 바꾸고, 통과 목표에 비례한 **안정 세입**을 보장한다.
- **핵심 메커니즘**: `penaltyToScore`(벌점 1당 +N점) + `settlementPctOfTarget`(목표 비례 안정 세입, 합계 20% 캡) + 게이지 직접 감소(보험). *(최소 점수 보장 settlementFloor는 로드맵)*
- **강점**: 산업·부패·포퓰을 **마음껏 쓰게** 해주는 능동 파트너. 벌점이 쌓일수록 재난대비기금이 오히려 점수↑.
- **약점**: 곱셈/스케일링이 없어 단독 상한은 낮음. 받쳐줄 점수원이 따로 필요.
- **시그니처**: 재난대비기금(환경·부패 벌점 1당 +3점), 복지 안전망(통과 목표의 20% 안정 세입), 무료급식(게이지·목표증가 완화).
- **차별점**: 과거의 "그냥 보험"에서 벗어나 **벌점을 점수로 전환**하는 고유 승리 보조 축을 가짐.
- **파트너**: 산업(환경 벌점→점수), 부패/포퓰리즘(게이지→점수, 디버프 완화), 주거.

### 환경 (Environment)
- **정체성**: **게이지 정화 + 환경 카운트 정산**. 깨끗한 도시를 유지하며 환경 카드 수로 정산을 쌓는다.
- **강점**: 녹지 조성·하천 복원·탄소중립(게이지 -), 자원순환 센터(정화 캔트립), 옥상정원(환경 연계),
  녹색수도 유물(환경당 +3), 그린벨트 지정 정책(매 턴 게이지 -1).
- **약점**: 산업과 동시 채용이 어려움(상극). 빌드 방향을 가른다.
- **후반 페이오프(구현됨)**: 친환경 박람회 — **환경 5장 이상 보유 시 전체 정산 ×1.3**
  (`settlementThresholdMult` 임계 배수). 환경 전문 덱의 후반 정체성 완성.
- **로드맵**: "산업 벌점 무효" — 미구현.
- **파트너**: 과학(친환경 기술 — 핵융합 발전소), 복지.

## 4. 정치형 태그 (하이리스크·하이리턴)

### 홍보 (PR)
- **정체성**: **즉발 버스트 + 군중 동원(연계)**. 지금 점수를 내되, 먼저 낸 카드 수에 비례해 커진다.
- **강점**: 저비용 즉발(현수막·대대적 홍보·도심 퍼레이드), 골목 유세단(홍보 연계), 초반 평가의 구원투수.
- **약점**: 엔진이 아니라 소모품. 지속/정산 빌드엔 기여 적음.
- **파트너**: 포퓰리즘(버스트 극대), 문화(앙코르 무대 재사용).

### 정치 (Politics)
- **정체성**: **약속(정산 고정 공약) + 합의(연계)**. 즉발 0 — 점수는 평가 정산 때 약속대로 들어온다.
- **강점**: 선거 공약(정산 +15)·개혁 법안(정산 +25) 같은 확정 수입, 공청회(정치 연계).
- **약점**: 즉발이 없어 초반 평가에 취약. 손패 사용 불가 카드 비중이 높음.
- **로드맵**: 조건형 공약("이번 주기 관광 5회 사용 시 +50") — 구현 시 정치의 하이라이트가 된다.
- **파트너**: 복지(안정 세입 결합), 포퓰리즘.

### 부패 (Corruption)
- **정체성**: **즉시 강력 + 벌점/리스크 누적**. 빠른 자원을 당겨오되 대가를 치른다.
- **강점**: "즉시 +예산/+점수 큼", "구매 비용 무시". 단기 폭발.
- **약점**: **부패 게이지** 누적 → 정산 시 큰 마이너스 또는 평가 페널티. 복지로만 억제 가능.
- **파트너**: 상업, 포퓰리즘, 복지(억제).

### 포퓰리즘 (Populism)
- **정체성**: **즉발 폭발 + 다음 평가 목표 상향**. 지금 표를 얻고, 다음 평가의 합격선을 높여 갚는다.
- **강점**: "사용: +대량 점수", 초반~중반 평가 통과력 최강.
- **약점**: "다음 평가 목표 +10%" 같은 **합격선 상향**이 누적. 5차에서 목표가 감당 못 할 만큼 커질 위험.
- **파트너**: 홍보(즉발 극대), 부패, 복지(디버프 완화).

## 5. 도시 아키타입 (빌드 정체성)

각 아키타입은 **메인 태그 + 서브 태그 + 핵심 엔진**으로 정의된다. 같은 목표 점수를
**서로 다른 수단**으로 달성한다는 것이 본 게임의 핵심 가치.

| 아키타입 | 메인 | 서브 | 승리 방식 | 난이도 |
|----------|------|------|-----------|--------|
| **관광 도시** | 관광 | 문화·교통 | 지속 점수 트리거를 한 턴에 폭주시켜 누적 | ★★☆ |
| **과학 도시** | 과학 | 교육·행정 | 덱 압축으로 과학 밀도↑ → 정산 배수 폭발 | ★★★ |
| **산업 도시** | 산업 | 상업·교통 | 고즉발 점수 연타, 환경 벌점은 복지로 상쇄 | ★★☆ |
| **문화 도시** | 문화 | 관광·교육 | 정산 "장당 점수"를 두껍게 + 축제 즉발 | ★☆☆ |
| **주거·복지 도시** | 주거 | 복지·교통 | 넓은 인구 베이스 × 안정 보정으로 꾸준히 | ★★☆ |
| **포퓰리즘 도시** | 포퓰리즘 | 홍보·부패 | 초반 폭발로 앞 평가 압도, 5차는 복지로 버팀 | ★★★★ |

> 각 아키타입의 **구체 빌드 예시(카드/유물 조합 + 턴별 점수 시뮬레이션)** 는
> [05_밸런스.md](05_밸런스.md) 의 "빌드 다양성 검증" 절에 수치로 제시한다.
