# 02. 태그 정체성 & 도시 아키타입

> 이 게임의 **최우선 설계 목표는 태그 중심 빌드 다양성**이다. 카드 타입(재물/액션/점수)은 "무엇을 하는가"이고,
> 태그는 "어떤 도시를 만드는가"이다. 각 태그는 고유한 **역할·강점·약점·시너지 파트너**를 가진다.

## 0. 15개 태그 한눈에

| 태그 | 분류 | 한 줄 정체성 | 주 파트너 | 견제/약점 |
|------|------|--------------|-----------|-----------|
| 상업 | 생산 | 예산 엔진의 왕. 구매력·추가 구매 | 관광, 산업 | 점수 자체 산출은 약함 |
| 산업 | 생산 | 고점수 폭탄. 단 환경 벌점 | 상업, 교통 | 환경 카드와 상극 |
| 과학 | 생산 | **곱셈(×) 전용** — 정산 전체를 증폭. 단독이면 0 | 문화·교육, 행정 | 곱할 기반 없으면 0 |
| 주거 | 기반 | 인구=정산 베이스. 카드 수 보너스 | 복지, 교통 | 단독으론 밋밋 |
| 교통 | 기반 | 드로우·체이닝 엔진 | 관광, 산업 | 점수 직접 산출 적음 |
| 행정 | 기반 | 액션·덱 정비·압축 | 과학, 모든 엔진 | 점수 직접 산출 없음 |
| 문화 | 가치 | **평면 가산(+)** — 곱셈 없는 안정 점수 기둥 | 과학, 관광 | 단독 상한 낮음 |
| 관광 | 가치 | 지속 점수 트리거 천국 | 문화, 교통 | 트리거 없으면 허당 |
| 교육 | 가치 | **누적 복리** — 학습 레벨을 런 내내 적립 | 과학, 행정 | 즉효성 0(장기전) |
| 복지 | 가치 | **벌점→점수 전환 + 목표비례 안정 세입** | 산업, 부패/포퓰 | 스케일링 없음 |
| 환경 | 가치 | 산업 견제·후반 글로벌 배수 | 과학, 복지 | 산업과 동시 채용 어려움 |
| 홍보 | 정치 | 즉발 점수 부스트 | 모든 즉발 빌드 | 일회성, 엔진 아님 |
| 정치 | 정치 | 공약(조건 달성 시 대박) | 복지, 포퓰리즘 | 조건 미달 시 꽝 |
| 부패 | 정치(하이리스크) | 즉시 강력 + 벌점/리스크 누적 | 상업, 포퓰리즘 | 벌점 관리 실패 시 붕괴 |
| 포퓰리즘 | 정치(하이리스크) | 즉발 폭발 + 후반 디버프 | 홍보, 부패 | 후반 마이너스 |

## 1. 생산형 태그 (예산·고점수 엔진)

### 상업 (Commerce)
- **정체성**: 예산을 불리고 추가 구매를 제공하는 **경제 엔진**. 모든 빌드의 윤활유.
- **강점**: `+예산`, `+구매`, "구매 시 점수" 같은 효과. 상업이 두꺼우면 매 턴 2~3장씩 산다.
- **약점**: 상업만으로는 점수가 안 난다. 반드시 점수 산출 태그와 결합해야.
- **시그니처 효과**: "재물 카드 사용 시 +예산", "이번 턴 구매한 카드 1장당 +점수".
- **파트너**: 관광(구매가 점수로), 산업(비싼 점수 카드 구매력).

### 산업 (Industry)
- **정체성**: **한 방 고점수**. 큰 숫자를 즉발/정산로 꽂지만 **환경 벌점**을 동반.
- **강점**: 카드당 점수 수치가 가장 높음. "공장 가동: +12점" 류.
- **약점**: 산업 카드 보유 수에 비례해 **환경 벌점(정산 시 -점수)** 누적. 복지/환경으로 상쇄 필요.
- **시그니처 효과**: 고즉발 점수 + "정산 시 산업 카드당 -2점(환경오염)".
- **파트너**: 상업(구매력), 교통(가동 체이닝), 복지/환경(벌점 상쇄).

### 과학 (Science) — 고유 동사: **곱셈(×)**
- **정체성**: **정산 배수 전용**. 스스로는 점수를 거의 못 내고, **다른 태그가 쌓은 정산 점수를 ×로 증폭**한다.
- **핵심 메커니즘**: `settlementGlobalMultPerTag` — 보유 과학 카드 1장당 **정산 전체 ×(+%)**. 총 배수는 하드 캡(×10).
- **강점**: 본체(문화/주거/산업/교육) 위에 곱해져 4·5차에서 폭발. 과학 카드가 많을수록 배수 ↑.
- **약점**: **단독이면 ×0 ≈ 0** — 반드시 점수 기반 태그와 결합해야 의미. 초반(기반 빈약)엔 약함.
- **시그니처**: 연구소(과학 1장당 정산 +8%), 스마트시티(+18%/장), 노벨상 유치 유물(+15%/장).
- **차별점**: 문화(평면 가산)와 달리 과학은 **곱셈만** 한다. 이것이 둘을 가르는 선.
- **파트너**: 교육(곱할 기반 = 학습 레벨 점수), 문화/주거(평면 기반), 행정(밀도↑).

## 2. 기반형 태그 (엔진 인프라)

### 주거 (Residential)
- **정체성**: **인구 = 정산 베이스**. 카드 장수/주거 수가 다른 점수의 곱셈 토대가 됨.
- **강점**: "주거 카드당 +점수", "덱의 카드 1장당 소량 점수". 넓고 얕게.
- **약점**: 단독으로는 폭발력 부족. 다른 태그의 배수를 받아야 빛남.
- **파트너**: 복지(인구 만족), 교통(통근), 과학(스마트 주거).

### 교통 (Transport)
- **정체성**: **드로우·체이닝 엔진**. 손패를 돌려 한 턴에 여러 엔진을 가동.
- **강점**: `+드로우`, `+액션`, "관광/산업 카드 사용 시 추가 발동".
- **약점**: 점수 직접 산출은 낮음. 무엇을 돌릴지(관광/산업) 정해야 의미.
- **시그니처 효과**: 국제공항(관광 카드 사용 시 +2점 지속), 지하철망(+2드로우 +1액션).
- **파트너**: 관광(지속 점수 증폭), 산업(가동 연쇄), 행정(액션 공급).

### 행정 (Administration)
- **정체성**: **액션 공급·덱 정비·압축**. 보이지 않지만 모든 엔진의 톱니.
- **강점**: `+액션`, 카드 폐기(트래시), 드로우 필터링, 비용 감소.
- **약점**: 점수 0. 순수 인프라. 과투자하면 점수 부족.
- **시그니처 효과**: 규제 완화(이번 턴 액션 +2), 시청 효율화(카드 1장 폐기 후 1장 드로우).
- **파트너**: 과학(정산 밀도), 산업(고비용 카드 운용).

## 3. 가치형 태그 (점수 콤보)

### 문화 (Culture) — 고유 동사: **평면 가산(+) + 즉발**
- **정체성**: **안정적인 점수 기둥**. 곱셈 없이 **꾸준한 평면 점수**(정산 장당 + 즉발 축제)를 낸다.
- **핵심 메커니즘**: `settlementPerTag culture`(문화 카드당 +N, 선형) + 즉발 점수(축제).
- **강점**: 변동 없이 두툼한 중간 점수. 과학의 **곱셈 대상이 되는 최고의 기반**.
- **약점**: 곱셈이 없어 단독 상한은 낮음. 예산 산출 없음(경제는 상업 의존).
- **시그니처**: 국립박물관(정산: 문화 카드당 +3), 도시 축제(사용:+5), 문화의 거리(문화·관광 장당).
- **차별점**: 과학(×)과 정반대 — 문화는 **절대 곱하지 않는다**. "안정 vs 폭발"의 안정 축.
- **파트너**: 과학(문화 기반을 ×로 폭발), 관광(테마·트리거), 교육(학습 레벨 기반 보강).

### 관광 (Tourism)
- **정체성**: **지속 점수 트리거의 천국**. "~할 때마다 +점수"를 가장 많이 보유.
- **강점**: 교통·문화와 결합 시 한 턴에 트리거가 폭주.
- **약점**: 트리거(다른 카드 사용)가 없으면 빈손. 엔진 의존도 높음.
- **시그니처 효과**: 국제공항(관광 카드 사용 시 +2점), 랜드마크(정산: 관광 카드당 +3점).
- **파트너**: 문화(테마 일치), 교통(트리거 양산).

### 교육 (Education) — 고유 동사: **누적 복리(시간 투자)**
- **정체성**: **장기 투자**. 점수를 "지금"이 아니라 **런 전체에 걸쳐 복리로** 쌓는다.
- **핵심 메커니즘**: **학습 레벨(eduLevel)** — 매 평가 주기 시작 시 *보유 교육 카드 수만큼* 누적 증가.
  교육 점수 카드는 정산에서 `학습 레벨 × N`을 낸다(`settlementEduLevel`).
- **강점**: 일찍 교육에 투자할수록 학습 레벨이 매 주기 쌓여 **후반에 거대한 평면 기반**이 됨 → 과학(×)과 환상의 조합.
- **약점**: **즉효성 0**. 1차엔 학습 레벨이 낮아 거의 점수가 안 됨. 인내가 필요한 빌드.
- **시그니처**: 도서관(학습 레벨 1당 +2), 교육청(+3/레벨), 종합대학(+5/레벨).
- **차별점**: 과학은 "이번 평가 ×", 교육은 "성장률 자체를 영구히 적립" — 기생 보조가 아니라 **자기 승리 조건**을 가짐.
- **파트너**: 과학(학습 레벨 기반을 ×로 폭발), 행정(덱 압축으로 교육 밀도↑).

### 복지 (Welfare) — 고유 동사: **하방 보장 + 벌점→점수 전환**
- **정체성**: **리스크를 자산으로**. 환경/부패 벌점을 **오히려 점수로** 바꾸고, 통과 목표에 비례한 **안정 세입**을 보장한다.
- **핵심 메커니즘**: `penaltyToScore`(벌점 1당 +N점) + `settlementFloor`(이번 평가 최소 점수 보장) + 게이지 직접 감소(보험).
- **강점**: 산업·부패·포퓰을 **마음껏 쓰게** 해주는 능동 파트너. 벌점이 쌓일수록 재난대비기금이 오히려 점수↑.
- **약점**: 곱셈/스케일링이 없어 단독 상한은 낮음. 받쳐줄 점수원이 따로 필요.
- **시그니처**: 재난대비기금(환경·부패 벌점 1당 +3점), 복지 안전망(통과 목표의 20% 안정 세입), 무료급식(게이지·목표증가 완화).
- **차별점**: 과거의 "그냥 보험"에서 벗어나 **벌점을 점수로 전환**하는 고유 승리 보조 축을 가짐.
- **파트너**: 산업(환경 벌점→점수), 부패/포퓰리즘(게이지→점수, 디버프 완화), 주거.

### 환경 (Environment)
- **정체성**: **산업 견제 & 후반 글로벌 배수**. 깨끗한 도시는 후반 모든 점수에 보너스.
- **강점**: "정산 시 산업 벌점 무효", "환경 카드 N장 이상이면 전체 정산 ×1.2".
- **약점**: 산업과 동시 채용이 어려움(상극). 빌드 방향을 가른다.
- **파트너**: 과학(친환경 기술), 복지.

## 4. 정치형 태그 (하이리스크·하이리턴)

### 홍보 (PR)
- **정체성**: **즉발 부스트**. 일회성으로 이번 턴 점수를 뻥튀기.
- **강점**: "이번 턴 즉발 점수 ×2", 저비용 즉발. 초반 평가 통과의 구원투수.
- **약점**: 엔진이 아니라 소모품. 지속/정산 빌드엔 기여 적음.
- **파트너**: 모든 즉발/포퓰리즘 빌드.

### 정치 (Politics)
- **정체성**: **공약**. 조건을 내걸고 달성하면 대박, 실패하면 꽝.
- **강점**: "이번 주기 관광 카드 5회 사용 시 +50점" 같은 목표형 보상.
- **약점**: 조건 미달 시 0. 빌드 일관성을 요구(=빌드 유도 장치).
- **파트너**: 복지(공약 보험), 포퓰리즘.

### 부패 (Corruption)
- **정체성**: **즉시 강력 + 벌점/리스크 누적**. 빠른 자원을 당겨오되 대가를 치른다.
- **강점**: "즉시 +예산/+점수 큼", "구매 비용 무시". 단기 폭발.
- **약점**: **부패 게이지** 누적 → 정산 시 큰 마이너스 또는 평가 페널티. 복지로만 억제 가능.
- **파트너**: 상업, 포퓰리즘, 복지(억제).

### 포퓰리즘 (Populism)
- **정체성**: **즉발 폭발 + 다음 평가 목표 상향**. 지금 표를 얻고, 다음 평가의 합격선을 높여 갚는다.
- **강점**: "사용: +대량 점수", 초반~중반 평가 통과력 최강.
- **약점**: "다음 평가 목표 +10%" 같은 **합격선 상향**이 누적. 5차에서 목표가 감당 못 할 만큼 커질 위험.
- **파트너**: 홍보(즉발 극대), 부패, 복지(디버프 완화).

## 5. 도시 아키타입 (빌드 정체성)

각 아키타입은 **메인 태그 + 서브 태그 + 핵심 엔진**으로 정의된다. 같은 목표 점수를
**서로 다른 수단**으로 달성한다는 것이 본 게임의 핵심 가치.

| 아키타입 | 메인 | 서브 | 승리 방식 | 난이도 |
|----------|------|------|-----------|--------|
| **관광 도시** | 관광 | 문화·교통 | 지속 점수 트리거를 한 턴에 폭주시켜 누적 | ★★☆ |
| **과학 도시** | 과학 | 교육·행정 | 덱 압축으로 과학 밀도↑ → 정산 배수 폭발 | ★★★ |
| **산업 도시** | 산업 | 상업·교통 | 고즉발 점수 연타, 환경 벌점은 복지로 상쇄 | ★★☆ |
| **문화 도시** | 문화 | 관광·교육 | 정산 "장당 점수"를 두껍게 + 축제 즉발 | ★☆☆ |
