# 04. 유물 설계 — 60개 프레임워크 & 대표 샘플

> 유물은 **카드보다 강력한 영구 효과**다. 상점에서 자금으로 사며, **슬롯 제한**(시작 3, 최대 6)이 있어
> 무한 적재가 불가능하다. 본 문서는 6대 역할 프레임워크 + 등급 체계 + 대표 샘플(약 30개) + 확장 규칙을 정의한다.

## 1. 유물 6대 역할

| 역할 | 설명 | 예시 컨셉 |
|------|------|-----------|
| **태그 강화** | 특정 태그의 출력/정산을 증폭 | 과학 정산 ×2 |
| **점수 배수** | 즉발/지속/전체 점수에 곱연산 | 이번 주기 전체 점수 +20% |
| **비용 감소** | 카드/유물/구매 비용 절감 | 모든 카드 비용 -1 |
| **드로우 보조** | 손패·드로우·핸드사이즈 강화 | 매 턴 +1 드로우 |
| **엔진 보조** | 액션·구매·시장 슬롯·덱 정비 | 매 턴 +1 구매 |
| **규칙 변형** | 게임의 기본 규칙을 바꿈 | 시장 슬롯 11칸 / 점수 카드 손패 패널티 제거 |

## 2. 등급 & 가격

| 등급 | 가격(자금) | 강도 | 상점 등장 비중 |
|------|-----------|------|----------------|
| 보통(Common) | 80 | 단일 소폭 효과 | 60% |
| 희귀(Rare) | 180 | 조건부 강효과/배수 | 30% |
| 전설(Legendary) | 350 | 빌드 정의급/규칙 변형 | 10% |

> 슬롯 제한 + 등급 가격 + 상점 새로고침 비용(20→+10)이 함께 **유물 인플레이션을 억제**한다.

## 3. 60개 분포 설계

| 역할 | 보통 | 희귀 | 전설 | 합 |
|------|------|------|------|-----|
| 태그 강화 | 9 | 6 | 3 | **18** (태그 15종 커버 + 듀얼 3) |
| 점수 배수 | 3 | 4 | 2 | **9** |
| 비용 감소 | 3 | 2 | 1 | **6** |
| 드로우 보조 | 4 | 2 | 1 | **7** |
| 엔진 보조 | 4 | 3 | 2 | **9** |
| 규칙 변형 | 2 | 4 | 5 | **11** |
| **합** | 25 | 21 | 14 | **60** |

> **태그 강화 18개**: 15개 태그 시그니처 각 1 + 인기 태그(상업/과학/관광) 듀얼/상위판 3.

## 4. 대표 샘플 유물 (약 30개)

> 표기: 등급 C=보통 / R=희귀 / L=전설.

### 4.1 태그 강화

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 관광청 인증 | 태그강화 | C | 관광 카드 사용 시 추가 +1점 |
| 산업 훈장 | 태그강화 | C | 산업 즉발 점수 +25% |
| 노벨상 유치 | 태그강화 | R | 과학 정산 점수 ×2 |
| 유네스코 등재 | 태그강화 | R | 문화 정산 점수 ×2 |
| 교통 마스터플랜 | 태그강화 | R | 교통 카드 사용 시 +1드로우(턴 2회까지) |
| 메가시티 선언 | 태그강화 | L | 메인 태그(보유 최다 태그) 정산 점수 ×2 |
| 녹색수도 | 태그강화 | L | 환경 카드 1장당 전체 정산 +3%(상한 +60%) |

### 4.2 점수 배수

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 시정 백서 | 점수배수 | C | 즉발 점수 +15% |
| 황금기 | 점수배수 | R | 이번 주기 5턴째 점수 ×2(피날레) |
| 표심 폭발 | 점수배수 | R | 한 턴에 점수 30+ 획득 시 그 턴 점수 +25% |
| 위대한 도시 | 점수배수 | L | 전체 도시 발전 점수 +20% (모든 출처) |

### 4.3 비용 감소

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 행정 간소화 | 비용감소 | C | 액션 카드 구매 비용 -1 |
| 규제 샌드박스 | 비용감소 | R | 모든 카드 비용 -1(최소 0) |
| 그림자 예산 | 비용감소 | L | 매 턴 첫 카드 1장 구매 무료. 부패 게이지 +1/턴 |

### 4.4 드로우 보조

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 시민 참여 | 드로우 | C | 매 턴 +1 드로우 |
| 스마트 행정망 | 드로우 | R | 매 턴 시작 시 손에 점수 카드 없으면 +2드로우 |
| 빅데이터 센터 | 드로우 | L | 손 크기 +2, 매 턴 +1액션 |

### 4.5 엔진 보조

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 복식부기 | 엔진 | C | 매 턴 +1 구매 |
| 도시계획국 | 엔진 | R | 시장 강제 추가 시 후보를 4장 중 1장 선택 |
| 추경 편성 | 엔진 | R | 매 턴 +2예산 |
| 시장 직속 TF | 엔진 | L | 매 턴 액션 +1, 구매 +1. 단 정산 점수 -5% |

### 4.6 규칙 변형 (전설 핵심)

| 이름 | 역할 | 등급 | 효과 |
|------|------|------|------|
| 광역 통합 | 규칙변형 | R | 시장 슬롯 +1 (최대 11칸) |
| 책임 면제 | 규칙변형 | R | 점수 카드의 손패 패널티 제거(빈 카드 무효) |
| 영구 집권 | 규칙변형 | L | 포퓰리즘/부패 후반 디버프 절반 |
| 도시 헌장 | 규칙변형 | L | 정산을 매 턴 종료 시에도 절반 적용(지속 정산화) |
| 표준화 정책 | 규칙변형 | L | 같은 카드 3장 보유 시 그 카드 효과 +1단계 강화 |

## 5. 유물 시너지 가이드 (아키타입별 추천)

| 아키타입 | 핵심 유물 1순위 | 보조 |
|----------|----------------|------|
| 관광 도시 | 관광청 인증 + 크루즈/공항 트리거 | 시민 참여, 도시계획국 |
| 과학 도시 | 노벨상 유치 + 메가시티 선언 | 빅데이터 센터, 규제 샌드박스 |
| 산업 도시 | 산업 훈장 + 황금기 | 추경 편성, 녹색수도(벌점 상쇄 겸 배수) |
| 문화 도시 | 유네스코 등재 + 비엔날레(카드) | 도시 헌장 |
| 포퓰리즘 도시 | 영구 집권 + 표심 폭발 | 황금기, 복지 카드 |

## 6. 유물 확장 규칙 (나머지 ~30개)

1. **태그 미러링**: 한 태그의 강화 유물을 나머지 태그로 복제(수치/트리거만 교체).
2. **등급 승급**: 보통 효과를 "조건부 ×2"로 올려 희귀, "무조건 + 규칙변형"으로 올려 전설.
3. **트레이드오프화**: 강효과 + 페널티(부패/디버프/정산 -%)로 전설 균형 잡기.
4. **빌드 전환 유물**: "메인 태그 기준" 처럼 빌드에 따라 대상이 바뀌는 범용 전설.

> 생성 시 슬롯 가치 검수: **전설 1슬롯 ≈ 보통 2~3슬롯**의 출력이어야 한다.
