# 05. 밸런스 — 평가 곡선 · 초보/고급 풀 · 무한콤보 · 추천 수치

## 1. 평가 단계 밸런스

### 1.1 목표 곡선

| 차수 | 목표 | 성장비 | 필요 평균 점수/턴 | 주력 엔진 | 자금(통과 시 ≈) |
|------|------|--------|-------------------|-----------|------------------|
| 1차 | 70 | — | 8.8 | 즉발(초보 풀) | ≈70~105 |
| 2차 | 160 | ×2.29 | 20 | 즉발 + 첫 엔진 | ≈160~240 |
| 3차 | 420 | ×2.63 | 52.5 | 지속/정산/회전 엔진 | ≈420~630 |
| 4차 | 900 | ×2.14 | 112.5 | 정산·주기 배수 + 유물 | ≈900~1350 |
| 5차 | 1800 | ×2.0 | 225 | 배수 곱연산 폭발 | — (클리어) |

> 자금은 목표 달성률 기반: 턱걸이 통과 = 목표의 100%, 초과분은 절반 비율로 가산, 목표×1.5 상한.
> 2차를 낮게(160) 잡은 이유: 플레이형 덱(트리거/러시/회전)은 엔진 완성이 3차 직전이라,
> 2차가 높으면 정산형만 살아남는 단일 전략 게임이 된다(아키타입 시뮬레이션으로 검증).

### 1.2 행정 처리 한도 (정산 = 낸 만큼)

정산 점수(보유 카드 기준: 카운터·복지 안정세입·교육레벨)는 **이번 주기에 낸 카드 수 × `settlementPerPlay`(=50)**
를 넘지 못한다. 없으면 5차 시작과 동시에 복지 안정세입(목표 40%)+정산 카운터만으로 목표를 자동 충족해
**액션 페이즈가 무의미**해지기 때문. 이 한도로:
- 무플레이 자동 통과 봉쇄 (0장 플레이 → 정산 0)
- 정산 덱도 드로우·액션 엔진을 돌려야 정산을 현금화 → 도미니언식 엔진 가치 회복
- deadInHand 클로그와 맞물림: 정산 카드를 많이 살수록 손패가 막혀 플레이가 줄고 한도가 낮아짐 → 드로우 투자 강제
- 시뮬레이션: 무플레이 뚱뚱덱 16승→5승, 드로우엔진 결합 정산덱 8승(엔진 투자가 보상됨)

설계 의도:
- **완만해지는 도약**: 성장비가 2.57→2.0으로 낮아져 초반에는 빌드 방향을 요구하고 후반에는 막힌 벽처럼 느껴지지 않게 한다.
- **정산 가중**: 후반일수록 "정산 1회"가 전체 점수의 50~70%를 차지하도록 설계 → 8턴째 빌드 완성 압박.
- **자금 램프**: 오버킬할수록 자금↑ → 다음 주기 유물/강화로 더 큰 곱셈. **잘하면 더 쉬워지는** 양의 피드백.
  단 슬롯/상점 무작위로 폭주는 억제.

### 1.2 난이도 안전판

- 1·2차는 **초보 풀(즉발)만으로 통과 가능**해야 한다(콤보 학습 전 구간).
- 3차부터 **시너지 1축**, 4차 **시너지 2축 또는 유물 2개**, 5차 **배수 곱연산**이 사실상 필수.
- 목표 미달 시 즉시 게임 오버지만, **복지 카드의 목표비례 안정 세입**(통과 목표의 20%를 보장 점수로)이 변수 완충.

## 2. 빌드 다양성 검증

### 2.1 자동 플레이 기준선

- 고정 시드 `[1, 2, 3, 7, 42]`의 1차 최종 점수는 `[100, 83, 91, 89, 121]`, 평균 **96.8**이다.
- 목표 70을 모두 통과하지만 평균이 목표의 2배를 넘지 않아, 기존 목표 50보다 초반 과잉 성장을 줄였다.
- 그리디 봇은 연계·정산 장기 투자를 완전히 이해하지 못하므로 2차부터 실패할 수 있다. 이는 초보 기준선이지 최적 플레이 증명이 아니다.
- 검증은 `tests/sim.test.ts`, 연계/시장 불변식은 `tests/combo.test.ts`가 담당한다.

### 2.2 아키타입 출력 방식

- **관광·문화**: 지속 트리거와 문화 정산을 함께 쌓아 매 턴과 평가에서 고르게 득점한다.
- **과학·교육**: 초반은 느리지만 누적 학습 레벨과 정산 전체 배수로 후반을 노린다.
- **산업·상업**: 즉발 점수와 예산이 강한 대신 환경·부패 관리 비용을 요구한다.
- **행정·교통**: 드로우·액션으로 덱 회전율을 높이고 새 연계 카드의 선행 태그를 마련한다.
- **복지·환경**: 위험을 상쇄하면서 목표 비례 안정 점수로 편차를 줄인다.
- **홍보·정치·포퓰리즘**: 빠른 점수 폭발 대신 다음 평가 목표가 증가한다. 증가율은 총 +80%로 제한한다.

### 2.3 v0.2 연계 카드

`골목 야시장`, `시민 과학제`, `대중교통 환승제`, `옥상정원 네트워크`, `참여예산 총회`, `골목 유세단`은
먼저 낸 같은 태그 카드 수만큼 점수를 얻는다. 손패 순서를 판단하게 만들되 카드별 상한으로 무한 증폭을 막는다.

## 2.5 가격-효율 곡선 원칙 (덱빌딩의 화폐 가치)

덱빌딩에서 카드 1장은 **드로우 슬롯을 차지하는 비용**을 함께 치른다. 약한 카드는 공짜여도 덱을 망친다
(도미니언에서 4코스트 '대장간'이 +3드로우인 이유 — 1코스트 차이가 거대한 밸류 격차다).
그러므로:

1. **가격이 오를수록 효율은 초선형으로 커진다.** 코스트 +1은 "효과 +1"이 아니라 "체급이 바뀐다"에 가깝다.
   - 1~2코: 소품 (캔트립, +3~5점, +1~2예산)
   - 3코: 기본기 (+2드로우 / +2액션 / +5예산(리스크) / +6~9점)
   - 4~5코: **엔진 코어** — 여기서부터 확 좋아져야 한다 (지하철망, 강트리거, 연계 코어)
   - 6~7코: 게임을 접수하는 한 장 (대기업 유치, 크루즈 터미널, 세계 박람회)
2. **티어(B/A/S)는 "가격"이 아니라 "등장 시기"다.** 낮은 티어는 싼 카드 위주 + 일부 비싼 카드,
   높은 티어일수록 비싼 카드가 많다 — 하지만 "A티어라서 비쌈/좋음"은 성립하지 않는다.
   같은 코스트라면 티어와 무관하게 비슷한 체급이어야 한다.
3. **같은 능력의 태그 스왑 복제 금지.** 같은 축을 쓰면 가격·규모 사다리를 명확히 하고,
   아니면 태그 고유 동사(02_태그정체성 §0.5)로 능력 자체를 갈라야 한다.

## 3. 초보자용 카드 풀

**선정 기준**: ① 효과가 한 줄 ② 자기완결(콤보 불필요) ③ 즉발/단순정산 ④ 리스크 없음.

| 이름 | 효과 | 왜 초보용 |
|------|------|-----------|
| 세금 징수 | +2예산 | 예산 개념 학습 |
| 소규모 공원 | 사용:+4점 | 즉발 점수 직관 |
| 도시 축제 | 사용:+5점 | 비용 대비 명확 |
| 공장 가동 | 사용:+9점(벌점1) | 고즉발 + 리스크 첫 학습 |
| 국립박물관 | 정산: 문화당 +3 | 정산 개념 학습 |
| 연구소 | 정산: 과학당 +2 | 정산 + 태그 수집 |
| 민원 처리 | +1액션 +1드로우 | 액션 체인 입문 |
| 버스 노선 | +2드로우 | 드로우 가치 체감 |
| 공공주택 | 정산: 주거당 +2 | 넓게 모으기 |
| 국고 | +3예산 +1구매 | 구매 확장 입문 |

> **초보 풀 약 40장**. 1·2차 평가는 이 풀 + 시작 덱만으로 통과 가능하도록 수치 보증(시뮬 §2.1의 52/154가 근거).

## 4. 고급 카드 풀

**선정 기준**: ① 배수/제곱/조건/체이닝 ② 본체 태그 밀도에 의존 ③ 유물과 곱연산.

| 이름 | 효과 | 고급인 이유 |
|------|------|-------------|
| 스마트시티 사업 | 정산: 과학 수 ×4 | 덱 압축·태그 집중 선행 필요 |
| 국가연구망 | 정산: (과학+교육)² ÷10 | 제곱식, 상한 관리 |
| R&D 보조금 | 과학 점수 +50%(턴) | 타이밍·조합 의존 |
| 세계 박람회 | 트리거 ×2 턴 | 지속 엔진 깔린 뒤 폭발 |
| 크루즈 터미널 | 관광/문화 사용 시 +3 | 트리거 양산 엔진 전제 |
| 전자정부 | +액션+드로우+첫점수×2 | 순서 최적화 보상 |
| 비엔날레 | 문화 정산 +50% | 정산 빌드 완성형 |
| 매표/대규모 공약 | 즉발 +18/+25, 후반 디버프 | 리스크 관리 |
| 규제 특례 | 산업 즉발 ×1.5(부패+1) | 게이지 관리 |
| 탄소중립 도시 | 산업 벌점 무효 + 전체 ×1.2 | 빌드 전환·상쇄 설계 |

> **고급 풀 약 30장**. 4·5차는 이 풀 없이는 사실상 불가. 시장 후보 가중치가 후반에 고티어를 더 띄움(01번 §3.3).

## 5. 무한 콤보 위험 분석 & 안전장치

> 덱빌딩 로그라이크의 고질병. "한 턴에 무한 반복 → 점수 무한"을 **구조적으로** 막는다.

### 5.1 위험 콤보 유형

| # | 콤보 | 메커니즘 | 위험도 |
|---|------|----------|--------|
| C1 | **순환 드로우** | `+2드로우+2액션`류가 그물처럼 자기 자원 초과 회수 → 덱 전체 무한 가동 | ★★★ |
| C2 | **지속 트리거 무한 발동** | "관광 사용 시 +점수" + 0코스트 자기 재사용 카드 → 같은 카드 무한 플레이 | ★★★ |
| C3 | **무료 구매 루프** | `그림자 예산`(첫 구매 무료) + "구매 시 +점수"(상권 활성화) + +구매 다수 | ★★☆ |
| C4 | **제곱 폭주** | `국가연구망`(제곱) + 카드 수 무한 증식 | ★★☆ |
| C5 | **배수 중첩** | 곱연산 유물·카드 여러 개 동시 → 지수적 점수 | ★★☆ |
| C6 | **지속 정산화 루프** | `도시 헌장`(매 턴 정산 절반) + 매 턴 정산 트리거 남발 | ★☆☆ |

### 5.2 안전장치 (설계 규칙)

1. **순(純) 자원 보존 법칙(C1)**: `+액션`과 `+드로우`를 **둘 다** 주는 카드는 **순증을 0 이하**로.
   (예: +2드로우 +1액션 카드는 자기 자신이 액션 1을 소비하므로 순액션 0). 순(+)액션 카드는 드로우를 주지 않는다.
2. **자기 재사용 금지(C2)**: 카드를 손/덱으로 **0코스트로 되돌리는 효과를 만들지 않는다**.
   되돌림이 필요하면 액션·예산 비용을 부과해 루프당 자원이 고갈되게.
3. **트리거 횟수 캡(C2)**: 모든 "지속 점수" 카드/유물은 **턴당 발동 상한**(권장 6~8회)을 명시. 상한 초과분 무효.
4. **구매 한도 + 유한 재고(C3)**: 추가 구매는 카드/유물로만 +되며 **턴당 구매 상한(권장 5)**.
   시장 각 더미는 **유한 재고**(종류당 8~12장)라 한 종류 무한 구매 불가.
5. **제곱·고차 상한(C4)**: 제곱/지수 카드는 **하드 캡** 부여(예: 국가연구망 정산 상한 +400점).
6. **곱연산 슬롯 제한(C5)**: 곱연산(×) 유물은 동시 **최대 2개까지만 발효**(3개째부터 가산 변환).
   카드 곱연산은 "이번 턴" 한정 + 빌드당 1~2장 등장 빈도로 제한.
7. **정산 1회 원칙(C6)**: 정산은 기본 **평가 시 1회**. `도시 헌장`은 예외적 "절반"이며 **턴당 정산 1회 캡** + 그 자체가 전설 1장.
8. **하방 비대칭**: 즉발 폭탄(포퓰리즘/부패)은 항상 **후행 페널티**를 동반해, 무한이 아니라 "빚"이 되게.

> 핵심 철학: **"무한"의 씨앗인 "자원을 순증시키며 반복 가능한 0비용 루프"를 카드 풀에서 원천 배제**.
> 폭발은 허용하되(빌드 보상), 그것은 항상 **유한한 자원·턴당 캡·슬롯 제한** 안에서의 폭발이어야 한다.

## 6. 추천 수치 밸런스 (마스터 시트)

### 6.1 자원/턴

| 항목 | 권장값 | 비고 |

| **평가 1주기당 턴 수** | **8** | 기존 5에서 늘림. 예산을 재물로만 버는 램프를 보완 |

> **프로토타입 밸런스 메모(갱신)**: 초기엔 기초 세수(턴당 예산)로 램프를 보조했으나,
> "예산은 0에서 시작해 재물 카드로만 번다"는 원래 설계를 살리기 위해 **기초 세수를 0으로 되돌리고

### 6.2 카드 효율 기준선 (재게시)

| 역할 | 공식 |
|------|------|
| 재물 | 예산 = 비용 + 1 (조건부 -1) |
| 즉발 점수 | 점수 = 비용 × 2.5 |
| 지속 점수 | 트리거당 = 비용 ÷ 1.5 (턴 2~3회 가정) |
| 정산 장당 | = 비용 ÷ 1 |
| 시너지 배수 | +25%~+50%, 곱연산 빌드당 1~2장 |
| 드로우/액션 | +1드로우 ≈ 1.5 / +1액션 ≈ 1.0 비용 |

### 6.3 리스크 게이지

| 게이지 | 누적원 | 정산 페널티 | 상쇄 |
|--------|--------|-------------|------|
| 환경 벌점 | 산업 카드 | -2점 × 벌점 | 환경/복지 카드, 탄소중립 |
| 부패 게이지 | 부패 카드/유물 | 게이지 5↑마다 평가 시 -10% | 복지, 무료급식 |
| 포퓰리즘 부담 | 즉발 폭탄 | **다음 평가 목표 점수 +8~12%**(총 +80% 상한) | 영구집권 유물, 복지 |

### 6.4 상점/메타

| 항목 | 권장값 |
|------|--------|
| 점수→자금 변환 | 1 : 1 |
| 유물 가격 | 80 / 180 / 350 (보통/희귀/전설) |
| 유물 슬롯 | 시작 3, 최대 6 |
| 카드 강화 | 50~120 |
| 시장 카드 직접 추가 | 60~150 |
| 특수 정책 | 100~300 |
| 카드 제거 | 30 |
| 상점 새로고침 | 20, 누를 때마다 +10 |

### 6.5 시장 후보 가중치 (재게시)

| 슬롯 | 규칙 |
|------|------|
| 1 | 메인 태그 70% / 무작위 30% |
| 2 | 서브 태그 50% / 무작위 50% |
| 3 | 항상 오프-컬러 |
| 공통 | 평가 차수↑ → 고티어 카드 등장 확률↑ |
